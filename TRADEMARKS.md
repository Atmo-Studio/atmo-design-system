The MIT license in [LICENSE](LICENSE) covers the code and the token values in this repository. It
does not cover the Atmo Studio name, the Atmo name, the Atlas name, the Brand OS name, or the Atmo
logomark. None of them is licensed for use, and nothing here grants permission to use them.

Fork the tokens freely. Ship them under your own name.

## Fonts

This repository contains no font files. Atmo's type is set in Satoshi Variable, licensed by Indian
Type Foundry through Fontshare under its own terms. Each product that uses these tokens loads the
font itself, under that license.
